# Frozen Derived Results

The files in this directory document one reviewed historical run of project version `3.0.0-risk-controlled`. Start with `analysis_report.html`, `performance_metrics.csv`, `integrity_checks.csv`, and `run_metadata.txt`. A prose interpretation is available in `../docs/RESULTS.md`.

These are derived research outputs, not raw market data and not future-performance evidence. The `temporal_holdout_diagnostic.csv` split is retrospective rather than true out-of-sample. Re-running the public-data pipeline later may produce different observations.
